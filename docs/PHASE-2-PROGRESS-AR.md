# تقدم المرحلة الثانية

## المنفذ في المصدر
- قائمة عائمة مشتركة لخيارات المكتبة والتحديثات، وأيقونات ودعم اتجاه اللغة وإغلاق بالنقر خارجها وإجراء الهروب لقارئ الشاشة.
- ربط الإجراءات الموجودة: الاستيراد، إدارة التصنيفات، تحديث المكتبة والتنزيلات.
- ألوان داكنة أعمق ونصوص وتحديد أوضح.
- استخدام glassEffect لشريط التبويبات والقائمة، مع خلفية معتمة عند تقليل الشفافية واحترام تقليل الحركة.
- الحد الأدنى للتطبيق iOS 26.0، وفحص SDK 26 في مسار البناء. الإنجليزية افتراضية والعربية اختيارية.

## ما لم يكتمل
- تشغيل JAR: لا يحتوي المشروع محرك JVM. قراءة الفهرس ليست تشغيلًا للإضافة.
- الدراسة السابقة لخلفية Tachimanga تشير إلى NativeChannel وتبعيات iOS يلزم بناء بدائلها من المصدر؛ لم يتم التحقق من بناء تلك الخلفية.
- فشل جلب مستودع الخلفية واتصال GitHub بسبب اتصال الوكيل الشبكي في بيئة العمل. لم تُنقل مكتبات النسخة المعدلة.
- لا تتوفر Xcode أو Swift محليًا. فحص الموارد لا يثبت نجاح تجميع Swift أو صحة المظهر على الجهاز.
- يلزم بناء IPA ثم اختبار القائمة باللغتين، أحجام النص الكبيرة، VoiceOver، تقليل الشفافية وشريط الزجاج فوق الأغلفة.
- بقية قوائم التفاصيل لم تتغير. لا ندعي مطابقة بصرية نهائية أو اكتمال المرحلة الثانية.

## بوابة إغلاق المرحلة
إضافة JAR حقيقية تنفذ البحث والتفاصيل والفصول والصفحات على iPhone، مع دورة تثبيت وتحديث وإزالة وتفضيلات وثقة؛ ثم نجاح البناء والمراجعة البصرية.

## استمرارية مفتاح المستودع
أضيف رفض تغيّر أو اختفاء المفتاح المحفوظ في مساري التحديث والإضافة المكررة للرابط، قبل الكتابة على القرص. يبقى الفهرس السابق محفوظًا عند الرفض وتظهر رسالة باللغتين. يسمح للمستودع غير ذي المفتاح باكتساب مفتاح في تحديث لاحق؛ هذه سياسة استمرارية فقط وليست تحققًا تشفيريًا من الفهرس أو JAR. أضيف اختبار لمساري الرفض وبقاء القرص والذاكرة دون تغيير ثم نجاح تحديث بنفس المفتاح وإعادة فتح التخزين. الاختبار لم يُشغّل لعدم توفر Swift محليًا.

## نتيجة البناء اللاحقة — تحل محل قيود الاتصال والبناء أعلاه
استُعيد اتصال GitHub ورُفعت التغييرات إلى main. فشلت المحاولة الأولى لأن Xcode الافتراضي كان 16.4؛ عُدّل المسار لاختيار Xcode مثبت مع SDK 26. نجحت اختبارات Swift وبناء ARM64 وتغليف IPA في التشغيل https://github.com/badrcoderman/MangaShelf/actions/runs/34790557845 للمراجعة 4bb253a. لا يزال فحص المظهر على iPhone وتشغيل JAR غير مكتملين.

## بدء اختبار محرك JAR — 14 سبتمبر 2026
استُعيدت نسخة الخلفية عند المراجعة المثبتة 2e52214106ffab02d13ff61a620def78414a8a45. فشل Gradle محليًا عند تنزيل التوزيعة قبل بدء التجميع؛ أضيف مسار GitHub Actions مستقل لتجميع السورس المثبت وحفظ السجل، دون إدخال ناتجه إلى IPA.

أضيفت أداة scripts/inspect_jar_backend.py لإنتاج JAR-BACKEND-INVENTORY.json من ملفات Git المتتبعة. أحصت 51 تصريحًا لدوال Java أصلية في 10 ملفات، و7 ملفات تستورد أنواع السحابة، و4 ملفات JAR متتبعة بما فيها Gradle wrapper. هذا جرد ساكن لا يثبت أن كل الدوال قابلة للوصول أو مطلوبة لكل مصدر. الملفات الأصلية الأهم للجسر: NativeChannel، NativeNet، Bitmap، McCookieManager، WebView، QuickJs وNativeString. لا يوجد تنفيذ Swift/C للجسر ضمن الملفات المتتبعة التي راجعناها.

حدود اختبار الخلفية: قد يستعمل التجميع تبعيات JAR المرفقة بالمستودع العام؛ نجاحه لا يثبت توافر سورسها ولا صلاحيتها للتوزيع في تطبيقنا. نحتفظ بها في checkout الدراسة ولا نضيفها إلى مشروع التطبيق. لم يُختَر أو يُدمَج JVM للآيفون بعد.
