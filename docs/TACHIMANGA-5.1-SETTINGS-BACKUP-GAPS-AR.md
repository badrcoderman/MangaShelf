# Tachimanga 5.1 — فجوات الإعدادات والنسخ والمظهر

تحديث طلب المستخدم: 20 أكتوبر 2026. النطاق المطلوب يشمل الوظائف وسير الشاشات،
وترتيب الإعدادات وخياراتها، والخلفيات والألوان والخطوط. الأولوية الحالية إكمال
التحليل قبل تنفيذ التطبيق. هذا سجل فجوات، وليس إعلان مطابقة أو إصلاح للنسخة المثبتة.

## ما تأكد من الكود الحالي

| المجال | حالة MangaShelf | العمل المطلوب ودليل الإغلاق |
|---|---|---|
| مدخل النسخ | [BackupHubView](../iOS/MangaShelf/SupportingSettingsViews.swift) يفصل الكتب المحلية عن مكتبة المصادر | مقارنة مدخل النسخ والشاشات المتفرعة والقوائم بالمرجع، ثم تنفيذ سير موحد واضح؛ BACKUP-05 |
| النسخ المحلية | [BackupPreferencesView](../iOS/MangaShelf/SettingsView.swift) يصدر JSON، ويستورد JSON لدمج التقدم | ليست استعادة جهاز جديد أو توافق TMB؛ BACKUP-01..04 |
| نسخ المصادر | [OnlineBackupView](../iOS/MangaShelf/OnlineLibraryViews.swift) يصدر JSON مستقلًا، ولا يضم صور الفصول | توثيق نطاق المحتوى ومعاينة الاستعادة وفصلها عن الملفات المنزلة؛ BACKUP-02 وBACKUP-06 |
| الصيغة المرجعية | [تحليل MCBackupPlugin](TACHIMANGA-5.1-PLATFORM-AR.md) يثبت ZIP خارجيًا فيه meta.json وcontents.zip، ومحتوى DB وprefs وJAR | قارئ مستقل مع تحقق الإصدار والـchecksum وتحويل مخطط البيانات؛ لا يكفي تغيير امتداد JSON إلى tmb؛ BACKUP-04 |
| قائمة النسخ والسحابة | التحليل يثبت مسارات ملفات محلية وiCloud ومراقبة ملفات؛ لم يختبر حسابًا أو تعارضًا | تتبع واجهة القائمة وتدفق تنزيل/تصدير/حذف النسخ، ثم جدولة واحتفاظ واختبار فشل؛ BACKUP-05 وBACKUP-07 |
| قائمة الإعدادات | [SettingsView](../iOS/MangaShelf/SettingsView.swift) يعرض أقسامًا، وبعض الوجهات تعلن أن الميزة غير متاحة | جرد كل صفحة وصف وخيار وقيمة افتراضية وحفظ وتأثير فعلي؛ SET-01..03 |
| المظهر | [AppearancePreferencesView](../iOS/MangaShelf/InterfacePreferences.swift) يعرض System/Light/Dark وعدد الأعمدة فقط | هذه ليست تغطية كل خيارات Tachimanga؛ جرد الخيارات المؤكدة وحالاتها أولًا؛ SET-01 وSET-04 |
| الألوان | [ShelfStyle](../iOS/MangaShelf/ShelfStyle.swift) يعرّف ألوانًا داكنة وفاتحة | وجود القيم في الكود لا يثبت استخدامها أو مطابقتها بكل شاشة وحالة؛ UI-06 |
| الخطوط | [TachiUI](../iOS/MangaShelf/TachiUI.swift) يستخدم خط النظام للنص وMaterial/icomoon لبعض الرموز | خطوط الرموز لا تثبت خط النص؛ يلزم حسم عائلة النص ووزنه وحجمه وارتفاع السطر والعربية؛ UI-07 |

فرق ملموس في مواصفة النص: [دليل الواجهة](INTERFACE-STYLE-AR.md) يذكر النص الفرعي
12 نقطة، لكن TachiRowLabel يستخدم ScaledMetric ابتدائيًا **13 نقطة**.
هذا اختلاف بين المواصفة والكود، ولا يثبت أيهما يطابق Tachimanga؛ تُحسم القيمة
بالدليل المرجعي قبل تعديلها.

## تفصيل التحليل قبل التنفيذ

### النسخ والاستعادة

- تسجيل شاشة المدخل، قائمة النسخ وحالاتها الفارغة، إنشاء نسخة، اختيار ملف،
  التفاصيل، التأكيد، التقدم، النجاح والفشل، وأفعال المشاركة والحذف حيث يثبت وجودها.
- تتبع خيارات النسخ التلقائي والوجهة والاحتفاظ وقيمها الافتراضية من مسار القراءة
  والكتابة والاستخدام؛ ظهور autoBackup ضمن whitelist لا يثبت الجدولة أو الافتراضي.
- تمييز TMB عن `.tachibk` المضغوط بـGZIP/protobuf، وتحديد مصفوفة دعم كل صيغة
  على حدة. لا يُعلن التوافق قبل عينات فعلية واختبار الاستيراد والتصدير.
- ربط محتوى النسخة بتفضيلات التطبيق والقارئ والمصادر والتصنيفات والتقدم.
  النصوص المحلية الحالية توضح أن ملفات الكتب والصور ليست مضمّنة.
- تحديد اتساق البيانات أثناء النسخ، ومسار المعاينة والتراجع قبل أي استبدال،
  واختبار نسخة تالفة/أحدث من المدعوم/مساحة غير كافية/إلغاء وفشل جزئي.
- استعادة بيانات الإضافة لا تمنح ثقة تلقائية بكودها؛ يلزم إعادة التحقق قبل أي تشغيل.

### الإعدادات

لكل صف يسجل الجرد: الصفحة والترتيب، العنوان والوصف والرمز، نوع التحكم، الخيارات،
القيمة الافتراضية بدليلها، مفتاح الحفظ، نطاق عام أو لكل عنوان أو مصدر، الجهة التي
تقرأه وتنفذ أثره، حالات التعطيل، وسلوك إعادة التشغيل والنسخ والاستعادة.
أي قيمة مجهولة تظل مجهولة إلى أن يثبتها التحليل؛ لا تُخترع خيارات من أسماء مفاتيح فقط.

يشمل الجرد العام والمظهر والمكتبة والقارئ والمصادر والتنزيلات والتحديثات
والتتبع والمزامنة والخصوصية والنسخ وحول، مع تمييز ما تعرضه العينة وما يعمل فعليًا
في MSL. اللغة الافتراضية إنجليزية والعربية اختيار صريح؛ اتجاه القراءة مستقل.

### الخلفيات والألوان والخطوط

قيم المشروع المرجعية الحالية، وليست قياسًا جديدًا من العينة:

| الدور | داكن |
|---|---|
| خلفية الصفحة | `#18181A` |
| ترويسة الإعدادات | `#24262C` |
| المحدد | `#3B3B3F` |
| اللون المميز | `#A8C2FF` |
| النص الأساسي / الثانوي | `#E7E8ED` / `#C7C9D0` |
| الحدود | `#34353A` |

تُراجع خلفية الصفحة والترويسة والقائمة والنافذة المنبثقة والخلفية أثناء التحميل،
والحالة المختارة والمعطلة والفواصل. تُراجع أيضًا خط النص الفعلي في اللغتين،
والأوزان والأحجام والمحاذاة والتفاف الوصف وارتفاع الصفوف وهوامشها والرموز.
أي موارد مضمّنة يجب أن تكون مرخصة؛ لا تُنسخ خطوط مجهولة الترخيص من العينة.

## شروط اعتبار المطابقة منجزة

1. سجل مرجعي مؤرخ من Tachimanga يحدد النسخة والجهاز واللغة والمظهر وحجم النص،
   مع فصل الحقائق الثابتة عن السلوك المشاهد على الجهاز.
2. لقطات مقابلة من MSL لنفس الصفحة والحالة والمقاس واللغة، ومراجعة فروق موثقة
   تشمل اللون والخط والموضع؛ لقطة تبويب «المزيد» لا تغطي الصفحات الداخلية.
3. تشغيل الخيارات والتحقق من حفظها وأثرها بعد إعادة التشغيل وبعد الاستعادة،
   مع فصل نجاح واجهة النسخ عن نجاح استعادة البيانات.
4. استعادة على تثبيت جديد وأخرى على مكتبة قائمة، ومراجعة التقدم والتصنيفات
   والإعدادات والتعارضات والفشل الجزئي وعدم فقد البيانات.
5. EN/AR وداكن/فاتح وDynamic Type وهاتف صغير وVoiceOver وReduce Transparency.
