# الأمن والرخص

- العينة المفكوكة والملفات المستخرجة مواد مرجعية غير موثوقة. لا تشغّلها ولا تضعها في Target التطبيق.
- جرد static لا يثبت الخلو من malware أو السلوك الشبكي الحي.
- افصل Tachimanga/Tachidesk/Mihon/Aidoku وأي مستودع آخر في سجل provenance مستقل، وثبّت revision والرخصة والملفات المنقولة.
- لا تنقل إعدادات توقيع أو Firebase secrets أو cookies أو provisioning profiles.
- افحص كل JAR قبل staging: الحجم، entry count، CRC، المسارات، SHA-256، التوقيع/الثقة، وحدود class version. لا تمنح صلاحية تنفيذ لمجرد أن الفهرس قبله.
- الشبكة HTTPS فقط، مع timeout/cancellation/redirect limits وعدم تسريب credentials عند تغير host.
- البيانات الخاصة بالمستخدم تبقى محليًا ما لم يوافق على خدمة محددة. لا ترفع صفحات المانغا إلى خدمة ترجمة افتراضيًا.
- احتفظ بإشعارات التراخيص داخل الحزمة، ولا تفترض أن أصول IPA أو خطًا أو كودًا مفككًا مسموح بإعادة توزيعه.
