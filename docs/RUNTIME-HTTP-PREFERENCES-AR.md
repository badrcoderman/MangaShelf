# مضيف HTTP وتفضيلات الإضافات — تقدم جزئي

هذا تنفيذ مستقل داخل `runtime-host`، خارج هدف iOS الإنتاجي. لا توجد IPA جديدة
تفعّل الإضافات، ولم تُشغّل الحزمة المنشورة أو الحزمة المعاد بناؤها لـMangaDex.

## ما نُفذ

- `HttpSource` مطابق للعقد المثبت: هوية MD5 الافتراضية المستقلة عن لغة الجهاز،
  والحقل القابل للاستبدال `headers$delegate`، وطلبات الصور ذات الروابط المحلولة،
  وحفظ path/query/fragment دون تخمين رابط صورة مفقود.
- `HostServices` و`AppInfo` لهوية MSL الفعلية، و`Context/Application` لمجلدات
  الملفات والكاش والتفضيلات. لا محاكاة لشاشات Android أو خدمات النظام.
- طلبات GET/POST و`await/awaitSuccess` فوق OkHttp 5.4.0 وOkio 3.18.1 مثبتين
  بالحجم وSHA-256 وSHA-512؛ طوبقت بيانات Maven Central قبل إدخال JAR في البناء.
- اتصال JVM حقيقي، وكاش HTTP محدود، وcookies في الذاكرة، وUser-Agent صريح.
  تُكشف صفحة تحقق Cloudflare كخطأ يحتاج المتصفح؛ لا يوجد حل للتحقق داخل التطبيق.
- الإلغاء يلغي الطلب وينتظر callback؛ يُغلق الرد الذي لم يستلمه المستدعي. يبقى
  أرشيف المصدر مفتوحًا حتى ينتهي تنظيف interceptors غير المتزامن.
- `SharedPreferences` للأنواع والقيم والمحرّر والمستمعين، مع نسخ المجموعات،
  ونشر ذري في الذاكرة، وكتابة مرتبة عبر ملف مؤقت واستبدال ذري. لا يُمسح الملف
  التالف تلقائيًا، وتظهر أخطاء `apply` عند flush/close.

صيغة التفضيلات ثنائية خاصة بـMSL، محدودة بـ4 MiB لكل ملف و4096 مفتاحًا.
الكتابات المقبولة التي لم تنتهِ محدودة أيضًا بـ32 MiB و4096 عملية؛ يُرفض تجاوز
الحد قبل نشر التعديل في الذاكرة. تظهر أخطاء الكاتب غير المتزامنة، بما فيها
الاستثناءات غير المفحوصة، عند flush/close ويمكن إعادة المحاولة.
الأسماء تُحوّل إلى SHA-256 لتفادي تصادم المسارات. المستمعون ضعفاء ويعملون خارج
الأقفال على خيط المستدعي؛ لا ضمان لخيط Android الرئيسي. يستخدم كاتب القرص
محمّل المضيف ولا يرث محمّل الإضافة. لا دعم لعدة عمليات تكتب المجلد نفسه.

## التحقق

```sh
python3 scripts/test-runtime-host.py
python3 scripts/test-runtime-preferences.py
python3 scripts/test-runtime-network.py
python3 scripts/test-extension-loader.py
```

كل فحص يحفظ نتيجته وبصمات المدخلات في `validation/`. تقارير الشبكة والتحميل
تميز صراحةً fixtures المؤلفة للمشروع عن الإضافة الحقيقية. فحص الشبكة يستخدم
خوادم HTTP/HTTPS محلية وشهادة اختبار مولدة؛ لا تُضاف شهادة الاختبار إلى ثقة
العميل الإنتاجي. فحوص الردود والإلغاء تفحص ملكية الرد وتأخر callback أيضًا.

نجح فحص التفضيلات المحلي في 16 حالة: الأنواع وإعادة الفتح، وعدم مشاركة
المجموعات، والترتيب المتزامن، وفشل الاستبدال وإعادة المحاولة، وأخطاء الكتابة
الخلفية، وحدود قائمة الانتظار قبل النشر، والمستمعون، والتلف والروابط الرمزية،
وUnicode، وسياق التطبيق ومحمّل كاتب القرص. لا يشمل ذلك واجهة إعدادات iOS.

نجح فحص الشبكة المحلي في 16 حالة، منها طلبات HTTP فعلية وUnicode ورفع بايتات
والتحويلات والكاش وcookies، ورفض شهادة غير موثوقة واسم مضيف غير مطابق مع نجاح
شهادة fixture الموثوقة لهذا العميل فقط، وإلغاء الطلب وملكية الردود المتأخرة.
يستخدم مخزن شهادة fixture بصيغة JKS لتفادي استهلاك حد الطلب في اشتقاق كلمة
مرور PKCS12 تحت `-Xint`. تُثبت DNS الخاصة بفحص TLS عنوان المستمع المحلي؛
لم تتغير ثقة العميل الإنتاجي أو DNS أو التحقق من اسم المضيف.

نجحت حالات التحميل الموقّع الـ19 محليًا؛ أضيف مصدر HTTP مؤلف في JAR منفصلة
موقعة بمفتاح اختبار، مع استدعاء فعلي عبر سجل المصادر. عند الإلغاء، ثبت بقاء
الأرشيف مفتوحًا أثناء تنظيف interceptor وقراءة مورده ثم إغلاقه بعد انتهائه.
طابقت فحوص ABI عدد 32 صنفًا و222 عضوًا عامًا/محميًا، ونجحت حالات النماذج
الـ14 والسجل الـ19. تبقى نتائج هذه الخطوة محلية حتى تسجيل تشغيل Actions جديد.

## المتبقي قبل تفعيل الإضافات

1. إكمال bootstrap الخاص بـInjekt وAndroid وتبعيات المصدر المثبت، ومنها
   compression وJSON/Okio وتهيئة التفضيلات. وجود أصناف Context لا يكفي وحده.
2. حسم النقل على iOS: تنفيذ JVM الحالي لا يستعمل NativeNet/URLSession، ولم
   تُثبت sockets أو TLS في VM الهاتف. نجاح فحص Java السابق لا يثبت الشبكة.
3. محوّل نماذج/أوامر إلى Swift يحفظ memo وترتيب الصفحات ويحوّل تواريخ الفصول
   من ميلي ثانية إلى ثوانٍ، ثم ربط المخزن وتأسيس ثقة الناشر وسحبها.
4. إثبات مصدر حقيقي كاملًا على iPhone قبل وصف نسخة بأنها تدعم الإضافات.
