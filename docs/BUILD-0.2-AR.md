# نسخة التطوير ٠.٢.٠ — تنفيذ الواجهة والتحقق

١١ سبتمبر ٢٠٢٦. هذا تحديث لسورس مشروعنا المستقل، وليس تعديلًا للـIPA المرجعية. لا توجد IPA ناتجة من هذه الجولة حتى الآن.

## ما تغير في الكود

- خمسة تبويبات: المكتبة، التحديثات، تصفح، السجل، المزيد، مع حفظ التبويب المحدد.
- شبكة أغلفة متقاربة، وعناوين فوق الصور، وشارات تقدم، وخيارات محفوظة للأعمدة والتصفية والفرز.
- تاريخ قراءة مجمّع حسب اليوم، وصور مصغرة وزر متابعة مباشرة.
- تبويب يعرض آخر الإضافات المحلية وتحديثات الفهارس الفعلية. لا يدّعي جلب فصول جديدة؛ محرك المصادر غير مدمج.
- إعادة تنظيم المزيد إلى القارئ والمظهر والتصنيفات والتخزين والنسخ الاحتياطي وحول.
- سجل تغييرات منسدل يعمل محليًا، يصف النسخة بأنها تطوير قيد التحقق، وإظهار أدوات المطورين بعد سبع ضغطات على الإصدار.
- اتجاه واجهة عربي وإعداد لغة عربية، مع رسائل عربية للأخطاء العامة وأخطاء الأرشيف. اتجاه قراءة الصور مستقل.
- أدوات تشخيص فعلية: أحداث محدودة في الذاكرة، معاينة وتصدير تقرير منقح، حدود الأغلفة، فحص البيانات، قياس التخزين، مسح ذاكرة الأغلفة، تحديث الفهارس وإعادة إعدادات القراءة والمظهر.
- تحديث المستودع الموجود مشروط ببقاء هويته؛ لا يعيد تحديث متأخر إدراج مستودع حذفه المستخدم.

المشروع لا يحتوي صفحة اشتراك أو مشاركة التطبيق أو اتصل بنا. تصدير بيانات المكتبة وتقرير التشخيص وظيفتان مستقلتان محفوظتان. لا توجد واجهات شراء أصلية جرى تجاوزها، ولا ملفات تشغيل من العينة المرفوعة في هدف البناء.

## المرجع البصري وحدود المطابقة

راجعت [الصورة الرسمية للتطبيق](https://tachimanga.app/assets/screenshot01.jpg) بصريًا. يظهر فيها ترتيب التبويبات وشبكة أغلفة بعناوين متراكبة. استُخدم ذلك مرجعًا للتخطيط الحالي. الصورة لا تغطي كل الشاشات أو كل إعدادات الإصدار 5.0، ولا تكفي لإثبات تطابق كامل. لم ينتج محاكي أو جهاز صورًا للنسخة الجديدة للمقارنة؛ لا توصف هذه النسخة بأنها مطابقة بالبكسل أو مكتملة الميزات.

## التحقق

- فحص بناء مشروع Xcode وربط الملفات دون إخفاقات في أداة تدقيق المشروع.
- فحص قواعد كتابة Swift بأداة tree-sitter، موثق في `validation/swift-syntax.json`. هذا لا يفحص أنواع Swift أو توفر واجهات SDK، ولا يقوم مقام التجميع.
- أضيفت ثلاثة اختبارات ذات أثر وظيفي: قياس المساحة دون تغيير البيانات، كشف تلف الملف دون استبداله، ومنع إعادة مستودع محذوف بسبب تحديث متأخر. أصبح الملف يحتوي ١٧ اختبار Swift؛ لم تُشغّل في هذه البيئة.
- محاولة `bash scripts/build-ios.sh unsigned` توقفت عند غياب Xcode برمز ٢، قبل بدء التجميع.
- فحص GitHub CLI أظهر غياب تسجيل الدخول؛ وفحص الوصول إلى المستودع الخاص لم يتمكن من المصادقة. لم يُدفع هذا التحديث أو يُشغّل مسار GitHub Actions في هذه المرحلة.

## بوابة المتابعة

بعد استعادة تسجيل الدخول، يُرفع هذا السورس ويُشغّل مسار البناء الموجود على macOS. يعالج أي خطأ ترجمة فعلي قبل وصف البناء بالناجح. بعد نجاح التجميع تُختبر الحزمة على جهاز، بما في ذلك الاستيراد والقارئ والعربية والتدوير والنسخ الاحتياطي. تشغيل JAR، الترجمة، تتبع الفصول، والتكافؤ الكامل مع Tachimanga تبقى أعمالًا غير منجزة، وليست أزرارًا وهمية أو ادعاءات في سجل التغييرات.
