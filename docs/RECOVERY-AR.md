# حفظ المشروع واستعادته

الأساس المسترجع هو ملف `MangaShelf-main 2.zip` المرفوع من المستخدم. بدأ سجل Git المحلي من commit `8a1f865`. هذا سجل مستعاد من أرشيف، وليس امتدادًا مثبتًا لتاريخ الفرع البعيد.

حزمة التسليم تتضمن مجلد `MangaShelf` كاملًا وملف `MangaShelf-history.bundle` في الجذر. لاستعادة المصدر وحده، فك ZIP. لاستعادة المصدر وسجل Git على جهازك:

```bash
git clone MangaShelf-history.bundle MangaShelf-restored
```

قبل الرفع إلى المستودع القائم، استنسخ النسخة البعيدة وقارن الملفات ثم انقل التعديلات إليها. لا تستخدم force push لهذا السجل المحلي، ولا تستبدل تاريخ المستودع البعيد بتاريخ الأرشيف.

قاعدة العمل: حفظ commit لكل دفعة قابلة للمراجعة، ثم التأكد من وصولها إلى المستودع البعيد أو حفظ حزمة استرجاع محدثة. commit المحلي وحده لا يحمي من إعادة ضبط مساحة العمل. لا تتضمن حزمة الاسترجاع رموز دخول أو شهادات توقيع.
