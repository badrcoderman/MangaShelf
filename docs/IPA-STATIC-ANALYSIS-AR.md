# تعليمات تحليل IPA المفكوك — تحليل ساكن فقط

## الهدف

استخدم هذه التعليمات لفهم الواجهة، الأيقونات، الفهارس، عقد الشبكة، ومحرك JVM دون تشغيل كود العينة. المسار المرجعي داخل حزمة التسليم هو `reference/decrypted-ipa/Tachimanga.app`، والأدلة المنظمة في `reference/ipa-analysis/Tachimanga-Organized`.

## خطوات ثابتة

1. احسب SHA-256 وسجل الحجم ومسار الأصل. لا تستبدل الأصل أثناء التحليل.
2. افحص قائمة الملفات والمسارات والامتدادات. ارفض الروابط الرمزية والمسارات المطلقة ومسارات `..` عند فك أي أرشيف.
3. افحص Mach-O بالقراءة فقط: magic، architecture، sections، cryptid، imports/exports، entitlements، privacy manifest، وFrameworks. وجود `cryptid=0` أو رمز JNI لا يثبت الأمان أو التشغيل.
4. اقرأ `Info.plist` وملفات strings وAssetManifest وFontManifest وNOTICES كبيانات. سجّل URL schemes، عناوين الخوادم، مفاتيح Firebase، وإعدادات User-Agent دون استخدام الأسرار.
5. افحص `MCHome.bundle/res.zip` بحجم أقصى وعدد إدخالات وCRC وحد فك الضغط. استخرج أسماء class والموارد النصية فقط.
6. استخدم الجردات وملفات `javap` الموجودة. لا تشغّل class أو JAR ولا تستدعي `main` ولا تحمل dylib/framework من العينة.
7. صنّف كل نتيجة إلى: مؤكد من البايتات، استنتاج قوي، فرضية، أو غير معروف. لا تحوّل اسم دالة أو constant-pool reference إلى call graph.
8. اربط كل أصل UI بخريطة glyph وSHA-256 ورخصته. لا تنسخ خطًا أو صورة إلى التطبيق قبل مراجعة إشعارات الترخيص.
9. اكتب تقريرًا جديدًا دون حذف التقارير السابقة، واحفظ الأدلة في مجلد جديد مع manifest.

## ما ثبت حتى الآن

- العينة تجمع Flutter وJVM/OpenJ9 وآثار JDK17، لكن ذلك لا يعطي محرك iOS قابلًا لإعادة البناء.
- توجد عقود JNI/NativeNet، وحقول Protobuf للمستودع والإضافة والمصدر والموارد، ومنها `jarUrl` برقم 501.
- توجد خطوط Material Icons وCupertinoIcons وIcoMoon وموارد PNG، مع مسارات Dart وفهارس bytecode.
- جرى استخراج 380 ملفًا من IPA وفحص 53 صورة Mach-O وفهرسة 27,686 صنف JVM؛ الأعداد وصف لنطاق التحليل وليست عدد ميزات أو دوال مستخدمة حيًا.

## ما لا يجوز ادعاؤه

لا تقل إن العينة آمنة لمجرد أن التحليل ساكن، ولا تقل إن كل الإضافات تعمل، ولا تقل إن كل صور Assets.car استُعيدت، ولا تقل إن محرك JVM يعمل على iPhone. اذكر حدود كل أداة ونسخة الإدخال.
