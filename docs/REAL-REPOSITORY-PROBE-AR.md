# التحقق من فهرس الإضافات المنشور

راجعت نسخة Keiyoushi المثبتة عند
[`229fddf8eeb9b44940fa10a77db3897c4783045d`](https://github.com/keiyoushi/extensions/tree/229fddf8eeb9b44940fa10a77db3897c4783045d).
يتضمن `index.json` و`index.pb` المضغوط بـGZIP عدد 1420 إضافة و2393 سجل مصدر.
بين روابط المواقع الوصفية 9 روابط HTTP، تشمل مصادر ذات خادم محلي قابل للإعداد.
كان `RepositoryIndex.validate()` يطبق سياسة تنزيل HTTPS على هذه البيانات
أيضًا، ولذلك يرفض الفهرس كاملًا قبل عرضه.

أصبح رابط موقع المصدر يقبل HTTP أو HTTPS بعنوان مطلق، دون بيانات دخول أو
محارف تحكم، وبحد طول ومنفذ صالح. تبقى روابط تنزيل الفهرس والحزمة والأيقونة
خاضعة لسياسة النقل الخاصة بها. قبول عنوان وصفي لا ينفذ طلبًا ولا يمنح
المحرك إذن شبكة؛ إعداد عنوان الخادم الفعلي وتشغيل الإضافة يحتاجان المحرك.

## المدخلات والتحقق

| الملف | الحجم بالبايت | SHA-256 |
| --- | ---: | --- |
| index.json | 1476319 | `567c190d85020531f9a71a2cf3148a8e23face92dacb5787f3081ab8d788c722` |
| index.pb | 109697 | `c0ef5ec28b646dbce0064210c05004a4cdbbce01f5f4711999da4463543eea68` |

`scripts/download-pinned-repository.py` ينزل Git blobs من commit المثبت،
ويتحقق من الحجم وSHA-256 وهوية Git blob قبل كتابة ملفات الاختبار. استخدام
JSON/base64 يحفظ بايتات GZIP دون التباسها مع ترميز محتوى استجابة HTTP.
اجتاز التنزيل المحلي هذه المطابقات. لم يُنزّل أو يشغّل السكربت أي إضافة.

`SourceWebsiteMetadataTests` يغطي قبول بيانات الموقع ورفض الروابط المشوهة
وبقاء شروط روابط الحزم والأيقونات، ويقارن ناتج قارئ Swift لصيغتي JSON وPB
عند توفير `MSL_REFERENCE_INDEX_DIR`. يتحقق أيضًا من معرفي MangaDex العربي
والإنجليزي ومن 61 سجل مصدر داخل الحزمة ورابط JAR المنشور.
يمكن تشغيل الفحص الفعلي في `ios.yml` بالخيار `repository_probe=true`؛
دون هذا الخيار يُسجّل اختبار العينة المثبتة كتجاوز صريح، وتعمل الحالات
الاصطناعية الثلاث دائمًا.

نجح الفحص الحقيقي والحالات الثلاث ضمن 121 اختبار Swift دون أخطاء في
[39804272061](https://github.com/badrcoderman/MangaShelf/actions/runs/39804272061)
عند `a713b24d59b12195f889d6e0d85ae56cc6c482cd`، مع بناء IPA ARM64 غير موقعة.
فُحص artifact وCRC وأعضاء IPA ومنصة iOS 26 وعدم وجود توقيع أو حمولات Java
داخل التطبيق؛ [النتيجة وحدودها](../validation/ios-39804272061.json).

`index.min.json` في هذا commit يحتوي رسائل ترقية للتطبيق فقط، وليس قائمة
الإضافات الكاملة. يشير `repo.json` إلى `index.pb` عبر `index_v2`؛ ينبغي
استخدام هذا المسار المدعوم في قارئ المستودع بدل قائمة رسائل الترقية.

هذا الفحص يثبت عقد بيانات المتجر ضمن العينة المحددة عند نجاحه. تشغيل
`SourceFactory` والتوقيع الموثوق والبحث والفصول والصور على iPhone بوابات
مستقلة ما زالت مطلوبة.
