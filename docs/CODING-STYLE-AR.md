# أسلوب كتابة الكود — MangaShelf

## Swift/SwiftUI

- استخدم Swift 5.9+ وواجهات SwiftUI المتاحة في SDK iOS 26 مع `@available` عند الحاجة.
- اجعل View طبقة عرض؛ ضع التحويلات والحفظ والشبكة في نماذج وخدمات قابلة للاختبار.
- استخدم `async/await` و`Task` مع إلغاء واضح. لا تترك مهامًا طويلة بلا مالك lifecycle.
- مرّر الحالة عبر `@State`, `@Observable`/`ObservableObject` وحقن الاعتماديات؛ لا تستخدم singleton للوصول إلى الشبكة أو القرص.
- استخدم `LocalizedStringKey` أو `L10n` لكل نص يملكه التطبيق. لا تترجم عنوان كتاب أو اسم مصدر.
- افصل لغة الواجهة عن اتجاه القارئ. لا تعتمد على `Locale.current` كقيمة اللغة المحفوظة.
- كل زر أو تبديل يجب أن يغيّر حالة حقيقية أو يوضح أنه غير متاح. لا تضف عناصر شكلية.
- حوّل الصفوف المتكررة إلى مكونات مشتركة مثل `TachiNavigationRow`, `TachiMenuRow`, `TachiToggleRow`, `TachiStepperRow` مع مساحة لمس مستقلة.
- حافظ على بنية Tachimanga: عنوان مركزي، تبويبات خمسة ثابتة، صفوف مسطحة، مسافات وحواف مقاسة، ولوحة خيارات عائمة محددة الحجم.
- تعامل مع Dynamic Type وVoiceOver وReduce Motion وReduce Transparency في كل شاشة جديدة.

## التخزين والشبكة

- اكتب الملفات ذريًا عبر ملف مؤقت ثم rename، واحتفظ بالنسخة السابقة عند فشل التحديث.
- طبّق حدودًا للملف والإدخالات والذاكرة والمهلة والتحويلات. لا تسمح HTTPS→HTTP ولا ترسل بيانات اعتماد إلى مضيف تغيّر.
- افصل `NativeNetworkContract` عن تنفيذ URLSession وعن جسر JNI.
- لا تحفظ token أو كلمة مرور في UserDefaults؛ استخدم Keychain عند تنفيذ الحساب.
- كل فشل قابل للاسترداد يجب أن يعطي خطأً قابلًا للعرض ويوقف retry غير المحدود.

## C وملفات الأرشيف

- التزم `-Wall -Wextra -Werror`، تحقق من overflow وCRC وNUL والمسارات والحدود قبل التخصيص.
- لا تفك ضغطًا إلى مسار يحدده الأرشيف. ارفض absolute و`..` والروابط الرمزية.
- لا تفتح JAR على أنه كود قابل للتنفيذ أثناء الفحص. مرحلة staging تحفظ SHA-256 وتحتاج سياسة ثقة مستقلة قبل المحرك.

## الاختبارات والتوثيق

- أضف اختبارًا للسلوك والحدود، لا اختبارًا يكرر شكل التنفيذ.
- سجّل الاختبارات التي شُغّلت فعلًا، وميّز فحص syntax أو static inventory عن build/type-check.
- حدّث الوثائق وخريطة الميزات عند تغير السلوك. لا تكتب «اكتمل» قبل بوابة القبول المرتبطة بجهاز iPhone.
