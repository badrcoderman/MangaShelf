## ما كشفت المقارنة في MangaShelf

رُوجعت الملفات الفعلية للقارئين والإعدادات والمكتبة ومخزن المصادر والتصفح والطابور
والنسخ وNativeBridge وExtensionRunner، مع أدلة الجرد الجديدة. لم تُختبر الواجهة
على محاكي أو جهاز في هذه البيئة.

| المجال | الحالة الحالية | الفجوة المؤثرة |
|---|---|---|
| المكتبة | شبكة/قائمة، تحديد متعدد، فئات وفلاتر، ملاحظات، سلة مهملات | اختبار جهاز وعد وقت نشط صحيح وتوحيد هويات المصادر |
| القارئ | CBZ، صفحات/ويب تون، اتجاهان، تقدم وعلامات وOCR في قارئ المصادر | صفحتان، اقتصاص، استئناف داخل صفحة ويب تون، دوران وتمرير تلقائي وتخصيص متقدم |
| الإضافات | فهارس وتجهيز حزم وثقة محفوظة وجسور تجريبية | JVM iOS مثبت ومسار إنتاج لتحميل مصدر فعلي |
| Java runner | موزّع تجريبي بعقد JSON صريح وأخطاء فعلية، اختُبر بمدخلات اصطناعية | لا توجد محولات لكائنات Tachiyomi أو SourceFactory/Rx/Android فعلية |
| Browse | MangaDex ومصدر محلي وصفوف حزم مفعلة | packageName يستخدم بدل sourceId، وpin الإضافات بلا فعل، وlatest يحتاج عقدًا مستقلاً |
| التنزيل | طابور متسلسل محفوظ مع pause/resume وكاش | استمرار طويل بالخلفية، backoff و429 وتوازي واستعادة بعد إنهاء التطبيق |
| النسخ | JSON ودمج metadata لكل مكتبة على حدة | نسخة موحدة وترقيات واستعادة جهاز جديد وتوافق نسخ Tachimanga/Mihon |
| التتبع/المزامنة/الترحيل | صفحات حالة ومعلومات | خدمات ومصادقة ومعالجة تعارضات واختبار تدفقات حقيقية |

ومن المشاكل المحددة: كانت أسماء مجلدات كاش الفصول تزيل علامات الترقيم وتسمح
بتصادم معرّفات مختلفة. عولج ذلك بـSHA-256 وترحيل مشروط بتطابق مالك الكاش،
مع ثلاث حالات اختبار Swift إضافية لم تُشغّل هنا. وصُححت تفاصيل العنوان لعرض
اسم المصدر الفعلي من الفهرس بدل قيمة MangaDex الثابتة. الشروط التفصيلية
والأولويات مسجلة في [TODO](../TODO.md)، بما فيها ما يحتاج إثبات جهاز.

## تحسينات القارئ المنفذة من هذه المراجعة

العينة الجديدة تحتوي علامات `CropBorderWithMangaId` و`InvertDoublePagesWithMangaId`
و`ReaderTapZonesSettingsScreen` و`DoublePageReaderModeV2`. هذه مراجع ساكنة
توجه المقارنة، ولا تكشف خوارزمية الاقتصاص أو كل إعدادات اللمس أو تصميم الشاشة.

نُفذت إعدادات مستقلة لكل عنوان، وملاءمة الصفحة أو العرض، والنقر المزدوج للتكبير،
ومناطق حواف/منتصف تتبع اتجاه القراءة. تشمل معالجة التوافق مع البيانات القديمة،
العودة إلى الإعدادات العامة، واستعادة إعدادات عناوين المصادر من نسخة بيانات المكتبة.
مظهر التطبيق ولغة الواجهة مستقلان عن إعدادات العنوان.

عولجت أثناء مراجعة الكود استعادة أدوات التحكم عند تحميل/فشل الصفحة، وفقدان
التكبير عند إظهار الأدوات، ونقص دمج إعدادات المصدر في النسخ. تحتاج الإيماءات
وسلوك UIScrollView والتحول بين أوضاع العرض تحققًا فعليًا على Xcode وجهاز.

أضيف `ReaderPreferencesTests.swift` بست حالات لاختبار البيانات والمنطق، و`ChapterCacheIdentityTests.swift` بثلاث حالات إضافية للكاش.
لم تُشغّل اختبارات Swift هنا لغياب Swift/Xcode؛ فحص الملفات لا يقوم مقام ترجمتها.

## إصلاح الموزّع التجريبي لـJava

كشفت مراجعة السورس أن إزالة fallback السابقة تخص Swift، بينما Java كان لا يزال
ينشئ نتائج بديلة عند فشل reflection. أزيل هذا السلوك، وأضيفت أخطاء مميزة لغياب
المصدر أو الطريقة وفشل الاستدعاء وعدم صلاحية الرد. أصبح تحميل المصدر يتطلب
instance فعلية ويحتفظ بسجل منفصل للحزمة ومعرّف المصدر.

الموزّع الحالي يستعمل طرقًا صريحة تُرجع JSON، وله حدود للحجم والعمق والتحقق من
المخطط. اجتاز 105 حالات اصطناعية على Java 27 مع تجميع يستهدف Java 8. هذا اختبار
عقد تجريبي؛ لا يثبت دعم نماذج Tachiyomi أو RxJava أو Android أو تشغيل iOS.

## إعادة الفحص

```bash
python3 scripts/review_tachimanga_ipa.py /path/to/Tachimanga.ipa --output validation/rea/tachimanga-5.1-static.json
python3 scripts/test_native.py
python3 scripts/test_packaging.py
python3 scripts/test_bridge.py --no-leak-check
python3 scripts/test_extension_runner.py
python3 scripts/check_ui_resources.py
python3 scripts/audit_project.py
```

أوامر REA الفعلية بدأت بـ`inspect-artifact <IPA> --format json` ثم
`inspect-artifact <main executable> --format json`. يحفظ JSON المستند الأصلي
بمعرّف الدليل والقيود، وفق [توثيق CLI](https://github.com/morluto/rea/blob/main/docs/cli.md).

على macOS/Xcode 26، يلزم `swift test` ثم `bash scripts/build-ios.sh simulator`
و`bash scripts/build-ios.sh unsigned`، وبعد ذلك توقيع المستخدم واختبار iPhone
ومراجعة لقطات المقارنة. [CHANGELOG](../CHANGELOG.md) يصف التغييرات دون إعلان
اكتمال هذه البوابات.
